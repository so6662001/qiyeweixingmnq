# 普讯AI销售 · 高保真效果图

面向钢铁贸易（兼配件）销售场景的企业微信相关界面高保真 HTML。

- 右侧栏：`docs/mockups/puxun-ai-sales-sidebar-hifi.html`

- 销售聊天台：`docs/mockups/puxun-sales-desk-hifi.html`

## 企微右侧栏模块

1. **报价**
   - 客户原话识别 → 明细核对 → **AI 多档方案**（优价/均衡/保障）
   - **报价清单**汇总（可改单价），一次性发给客户
   - **生成 PDF**，底部附带**小程序议价链接**，客户可自行进页议价
   - 侧栏底部常驻本客户**报价历史**（已发送 / 议价中 / 已成交 / 已过期）
2. **订单**：按当前客户查近单 / 状态 / 生成进度回复
3. **库存价格**：查现货与挂牌价，支持「加入报价清单」
4. **发票**：查已开/待开，发送发票说明给客户

## 销售聊天台

从推送卡片「打开聊天台」进入的工作台（三栏）：

1. **会话列表**：待跟进 / 询价中 / 人工中筛选  
2. **中间聊天**：客户 / AI / 人工消息，AI 推荐现货可加入报价  
3. **右侧客户栏**（对齐企微私聊侧栏能力）  
   - 顶部画像：欠款（预收/应收/订单应收）、应收利息、近月采购量、等级/类型、最近采购日、活跃/沉睡/流失、走量/利润客户  
   - 订单、库存、发票、报价清单、购买历史、上一单  
   - 历史/上一单/库存均可**带价加入当前报价**，并一键发报价单  

## 客服 → 销售员推送

客户直连微信客服时，助手自动回复并推送销售员。效果图对比「长文裸链接」与优化后的**结构化卡片**（客户名、意向标签、原话、助手摘要、打开聊天台）。

客户上下文常驻顶部，与当前企微会话绑定。
