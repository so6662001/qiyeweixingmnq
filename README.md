# 普讯AI销售 · 企微右侧栏效果图

面向钢铁贸易（兼配件）销售场景的企业微信「聊天右侧栏」高保真 HTML。

## 打开方式

直接用浏览器打开：

- 索引：`docs/mockups/index.html`
- 右侧栏：`docs/mockups/puxun-ai-sales-sidebar-hifi.html`

## 模块

1. **报价**：客户原话识别 → 明细核对 → 建议回复发送  
2. **订单**：按当前客户查近单 / 状态 / 生成进度回复  
3. **库存价格**：查现货与挂牌价，支持「加入报价」  
4. **发票**：查已开/待开，发送发票说明给客户  

客户上下文常驻顶部，与当前企微会话绑定。
