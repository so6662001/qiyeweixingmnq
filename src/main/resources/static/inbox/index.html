架构与合规

  • 个人微信：OpenClaw 收发，走腾讯官方 iLink Bot API，非逆向。
  • 企业微信：会话内容存档只读入站，需成员与客户已授权。
  • 回复统一由 OpenClaw 发出，两个通道行为一致。
  • 凭据来自环境变量，消息不落媒体文件。
