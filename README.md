## 企微右侧栏模块

1. **报价**
   - 客户原话识别 → 明细核对 → **AI 多档方案**（优价/均衡/保障）
   - **报价清单**汇总（可改单价），一次性发给客户
   - **生成 PDF**，底部附带**小程序议价链接**，客户可自行进页议价
   - 侧栏底部常驻本客户**报价历史**（已发送 / 议价中 / 已成交 / 已过期）
2. **订单**：按当前客户查近单 / 状态 / 生成进度回复
3. **库存价格**：查现货与挂牌价，支持「加入报价清单」
4. **发票**：查已开/待开，发送发票说明给客户

## 销售聊天台

从推送卡片「打开聊天台」进入的工作台（三栏）：

1. **会话列表**：待跟进 / 询价中 / 人工中筛选  
2. **中间聊天**：客户 / AI / 人工消息，AI 推荐现货可加入报价  
3. **右侧栏**（视觉与交互对齐企微右侧栏效果图）  
   - 品牌头 + 紧凑客户条（欠款/近月采购一览；点击展开画像 KPI）  
   - 四等分页签：报价 / 订单 / 库存价格 / 发票  
   - 报价页内含：报价清单、购买历史、上一单、报价历史（聊天台特有能力保留）  
   - 历史/上一单/库存均可**带价加入当前报价**，并一键发报价单（含小程序议价入口说明）  

## 客服 → 销售员推送（定制化卡片）

**可以做成定制化卡片。** 推荐用企微应用消息卡片 / 小程序卡片 / 模板消息，按意图套模板：

- 询价提醒卡、意向不明卡、超时催办卡
- 字段可配置开关（客户、原话、识别摘要、助手动作、欠款提醒等）
- CTA 进入聊天台，长 URL 不暴露给销售员

效果图：`docs/mockups/puxun-sales-push-notify-hifi.html`（可切换模板、开关字段预览）

客户上下文常驻顶部，与当前企微会话绑定。
